# 付文星 · 个人主页

数据科学与大数据技术专业大一学生的个人主页，记录象棋、AI 兴趣和从零开始的学习计划。

## 内容说明

目前暂无公开作品。页面中的练习方向和四周安排均为计划，不能作为已完成项目或已掌握技能使用。图形为装饰或示意，不代表实际成果。主页由 AI 辅助搭建。

## 本地查看

用浏览器打开 index.html 即可，无需安装依赖。请将 index.html、style.css 和 script.js 放在同一目录。

- index.html：个人介绍、练习计划和学习安排。
- style.css：页面外观、手机布局与打印样式。
- script.js：练习计划筛选和打印按钮。

## GitHub Pages

使用 main 分支的根目录发布。仓库根目录中的 .nojekyll 表示直接发布静态文件。

官方说明：[GitHub Pages 快速入门](https://docs.github.com/en/pages/quickstart)。
